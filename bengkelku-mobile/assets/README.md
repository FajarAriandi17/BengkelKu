# assets/

Aset statis aplikasi BengkelKu.

- `logo/` — `logo.svg` (pin lokasi biru + siluet motor). Ekspor PNG untuk ikon aplikasi (`flutter_launcher_icons`).
- `fonts/` — Plus Jakarta Sans (letakkan file .ttf: Regular/Medium/SemiBold/Bold/ExtraBold). Terdaftar di `pubspec.yaml`.
- `illustrations/` — ilustrasi empty state, sukses, onboarding (SVG/PNG).
- `icons/` — ikon kustom bila ada (gaya garis, warna `ink`).
- `animations/` — Lottie/Rive untuk sukses pembayaran, loading, dsb. Nonaktifkan saat Reduce Motion.

Catatan: unduh font Plus Jakarta Sans dari sumber resmi (OFL) dan taruh di `fonts/`.
